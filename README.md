# 🌑 Shadow Lands — Telegram MMORPG

## 🚀 Replit — запуск и обновление (2 шага)

### Обновить код с GitHub
1. Открой админку → **⚙️ Настройки** → нажми **🔄 Обновить с GitHub**
2. Подожди 5 секунд — сервер перезапустится сам. Обнови страницу.

> Если не перезапустился: нажми **Stop** → **Run** в Replit.

### Первый запуск на Replit
1. Создай Repl → **Import from GitHub** → вставь `https://github.com/AlfaGideon/TG-MMO-RPG.git`
2. Нажми **Run**. Открой Webview — это админка.
3. В админке вставь токен от @BotFather → **Сохранить** → **Запустить бота**.

## ☁️ Render.com (бесплатно, 24/7)
1. Форкни репозиторий на GitHub
2. [render.com](https://render.com) → New + → Web Service → выбери свой форк
3. Настройки:
   - **Build**: `pip install -r requirements.txt`
   - **Start**: `python launch.py`
   - **Plan**: Free
4. После деплоя открой URL → админка → вставь токен → запусти бота.
