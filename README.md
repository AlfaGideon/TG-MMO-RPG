# 🌑 Shadow Lands — Telegram MMORPG

Тёмно-фэнтезийная MMORPG в Telegram с полностью inline-интерфейсом и веб-админ-панелью.

## 🚀 Быстрый старт

### 1. Настройка окружения

```bash
cp .env.example .env
# Отредактируй .env — укажи BOT_TOKEN от @BotFather
```

### 2. Локальный запуск (без Docker)

```bash
# Создай виртуальное окружение
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установи зависимости
pip install -r requirements.txt

# Запуск бота
python -m bot.main

# Запуск админ-панели (в другом терминале)
python -m admin.main
```

### 3. Docker

```bash
docker-compose up --build
```

- Бот работает в фоне
- Админ-панель доступна на http://localhost:8000

## 🎮 Возможности

- **Inline-интерфейс** — вся игра через кнопки, без команд
- **4 класса**: Воин, Маг, Разбойник, Жрец
- **Локации**: безопасные, опасные, подземелья, боссы
- **Боевая система**: пошаговые бои с монстрами
- **Инвентарь**: экипировка, расходники
- **Магазин**: покупка предметов за золото
- **Прокачка**: уровни, статы, опыт
- **Топ игроков**: по уровню и золоту

## 🛡 Админ-панель

Веб-интерфейс на FastAPI с:
- Dashboard (статистика, последние бои)
- Список игроков с поиском
- Управление предметами
- История боёв

## 🗂 Структура проекта

```
TG-MMO-RPG/
├── bot/              # Telegram бот (aiogram 3)
│   ├── handlers/     # Обработчики команд и кнопок
│   ├── keyboards/    # Inline-клавиатуры
│   ├── middlewares/  # Middleware (сессии БД)
│   └── utils/        # Тексты и утилиты
├── admin/            # Веб-админка (FastAPI)
│   ├── templates/    # HTML-шаблоны
│   └── static/       # CSS
├── core/             # Ядро
│   ├── models.py     # SQLAlchemy модели
│   ├── database.py   # Подключение к БД
│   └── enums.py      # Перечисления
├── docker-compose.yml
├── requirements.txt
└── .env.example
```
