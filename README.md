# 🌑 Shadow Lands — Telegram MMORPG

Игровой движок и админ-панель **целиком на Python**.
`index.html` — только загрузчик: поднимает Python в браузере (Pyodide) и отдаёт
ему управление. Игровой логики на JavaScript нет.

---

## 🖥 Запуск админки (превью в Arena / локально)

Открой **`index.html`** через preview или локальный сервер:

```bash
python3 -m http.server 8000     # затем http://localhost:8000/index.html
```

> Через `file://` не заработает — модули подгружаются по fetch.

Дальше в панели: вкладка **🤖 Бот** → вставь токен от [@BotFather](https://t.me/BotFather)
→ **Запустить бота**. Бот начнёт отвечать в Telegram, пока открыта вкладка.

### Если бот не стартует

Telegram с осени 2025 отклоняет запросы с браузерным User-Agent. В разделе
**🤖 Бот → Транспорт** переключи режим с «Напрямую» на любой прокси-релей
(corsproxy / allorigins / codetabs) или укажи свой и нажми «Применить».
Для постоянной работы 24/7 используй серверный запуск (см. ниже).

  itemui.py             общий вид списков предметов: номера-эмодзи, страницы

Правила модульности (их стережёт `tests/test_wiring.py`):
`engine/` не импортирует ни `js`, ни `webapp`; `pages/*` только возвращают HTML-строки
и не трогают DOM; ни один файл не длиннее 320 строк; каждый `data-act` из разметки
обязан иметь обработчик в `actions/`.

### Как модули взаимодействуют

```
index.html ──fetch .py──> Pyodide FS ──> webapp/boot.py
                                             │
                    webapp/app.py ───────────┴──── webapp/pages/*.py (HTML-строки)
                          │
          ┌───────────────┼────────────────┐
   webapp/telegram.py  engine/storage.py  webapp/dom.py
          │                   │
   webapp/transport.py   engine/game.py ──> combat / world / rules / texts / data
          │
   api.telegram.org
```

`engine/` ничего не знает ни про браузер, ни про Telegram — его можно
подключить к серверному боту без изменений.

## 🎮 Что умеет игра

- **10 классов** из коробки, новые добавляются из админки без правки кода
- Случайные стартовые статы (−10 %…+20 %) с 10 попытками переката
- Шесть школ магии: у героя от нуля до двух предрасположенностей
- Прокачка со своим приростом статов у каждого класса, экипировка по слотам
- Бесшовный мир: 5 локаций по 100 клеток, переходы по границам
- Движение в 8 направлениях, осмотр клетки, ASCII-карта
- Пошаговый бой: атака, защита, умение, побег, криты — с учётом экипировки
- **Живой мир**: мобы ходят по карте, держат популяцию и респавнятся
- **Уникальный лут**: у каждого предмета свой ID со значком происхождения
- **История предметов**: кто добыл, у кого побывал, за сколько ушёл
- **Аукцион** между игроками и скупщик-NPC
- **Реликвии** в единственном экземпляре и праздничные трофеи
- **Крафт и заточка** у NPC-ремесленников, сундуки, лавка, зелья, отдых

### 🆔 Уникальные предметы

Предмет в базе — это *шаблон*. Каждый выпавший, купленный или скрафченный
экземпляр — отдельная строка `item_instances` со своим коротким ID и
собственными статами. **Перед ID стоит значок способа получения**, поэтому
происхождение вещи видно с одного взгляда:

| Значок | Откуда | Значок | Откуда |
|---|---|---|---|
| ⚔️ | выбито в бою | 🏪 | куплено в лавке |
| 📦 | найдено в сундуке | 🔁 | прошло через аукцион |
| 🕳 | добыто в подземелье | 🎄 | праздничный трофей |
| 🔨 | изготовлено | 🌟 | единственное в мире |
| 📜 | награда за задание | 🛠 | выдано администратором |

```
⚔️IT-D55CA5C1   Добротный Кинжал теней   ← выбит из моба
🔨IT-E6ED3800   Выверенный Стальной меч  ← скован в кузнице
🔁IT-D55CA5C1   тот же кинжал после продажи на аукционе
```

Значки особых меток важнее исходного источника: реликвия всегда светится
🌟, праздничная вещь — 🎄, а торгованная — 🔁. Ресурсов и расходников это
не касается: они складываются в стопки и своего ID не имеют.

Что именно катается у экземпляра:

| Что катается | Как |
|---|---|
| **Качество** | 100 % ± `stat_variance` шаблона (по умолчанию ±15 %), треугольное распределение — середина вероятнее краёв |
| **Статы** | базовое значение × качество × множитель редкости, плюс независимый джиттер ±6 % на каждый стат |
| **Редкость** | небольшой шанс (≈6 % + удача) получить ступень выше шаблонной |
| **Префикс** | по качеству: «Ржавый» → «Крепкий» → «Мастерский» → «Легендарный» |

Удача персонажа слегка смещает броски вверх и повышает шансы дропа.
Расходники и материалы не катаются — они складываются в стопки.

### 📖 История предмета

У каждого именного экземпляра ведётся летопись: кто добыл, из кого выбил,
у кого побывал, за сколько уходил. Поэтому вещь, купленная на аукционе,
приходит к новому владельцу **не пустой**:

```
⚔️ 28.07 выбит в бою — Аня (Теневой призрак)
📢 28.07 выставлен на аукцион — Аня за 150🪙
🔁 28.07 продан на аукционе — Боря за 150🪙 (куплен у Аня)
⚡ 29.07 заточен — Боря до +3
```

История видна игроку в карточке предмета и администратору на странице
экземпляра. Чем больше сделок прошла вещь, тем выше её оценка на аукционе.

### ⚖️ Аукцион

Игроки продают друг другу именные вещи по принципу «купить сразу»:

- продавец выбирает цену из готовых вариантов (от «💸 быстро» до
  «🤑 очень дорого»), опираясь на оценку аукциона;
- пока лот висит, вещь физически лежит на витрине, а не в сумке;
- покупателю уходит предмет со всей историей, продавцу — деньги за
  вычетом 5 % комиссии;
- непроданный за сутки лот сам возвращается владельцу;
- одновременно можно держать до 5 своих лотов.

**Скупщик Молчун** подстраховывает рынок: выкупает вещь мгновенно
(примерно за 55 % оценки) и перевыставляет её с наценкой. Деньги приходят
сразу, а предмет не пропадает из мира и сохраняет летопись.

### 🌟 Реликвии и 🎄 праздничные вещи

- **Единственные в мире** существуют ровно в одном экземпляре. Как только
  реликвия кому-то досталась, она исчезает из всех таблиц лута — второй
  такой не будет. Вернуть её в розыгрыш можно в админке
  (**Контент → 🎄 События**).
- **Праздничные** падают, только пока включено соответствующее событие
  (зимняя стужа, праздник жатвы, ночь духов). Выключил событие — вещь
  снова недоступна, но у тех, кто успел, она осталась с меткой 🎄.

### 🔮 Предрасположенность к магии

Шесть школ: 🔥 огонь, ❄️ лёд, ⚡ гроза, 🌑 тьма, 🌿 природа, ✨ свет.
При создании героя бросается дар — **от полного его отсутствия до двух
школ сразу**:

| Ступень | Множитель | Метка |
|---|---|---|
| Искра | ×0.6 | ◦ |
| Дар | ×1.0 | • |
| Сильный дар | ×1.4 | ✦ |
| Талант | ×1.8 | ✸ |

Шансы зависят от класса: у мага и некроманта дар почти гарантирован (и
часто двойной), у воина с берсерком магия — редкая случайность. Класс
также склонен к своим школам: некроманту вчетверо чаще выпадает тьма,
жрецу — свет и природа.

Дар не заменяет статы, а усиливает умение в бою и работает вместе с
магическими фокусами (жезл пламени, посох инея и т. п.): если школа
предмета совпадает с даром героя, бонусы складываются.

### 🎲 Случайные стартовые статы

Герой больше не рождается с одинаковым для всех набором. Статы катаются
от базы класса в диапазоне **−10 %…+20 %**, и при создании даётся
**10 попыток переката**:

```
🔮 Тестер — Маг
👍 Хороший бросок — 107% от базы класса
💪 Сила: 5      🧠 Интеллект: 18 (+2)   ❤️ HP: 88 (+8)
🏃 Ловкость: 9  🛡 Выносливость: 8      💙 MP: 132 (+12)
🎲 Осталось попыток: 7
```

Перекат заменяет текущий бросок — вернуться к предыдущему нельзя, так что
решать надо на месте. Принял бросок или потратил все попытки — статы
фиксируются навсегда. Магический дар бросается один раз и перекатом
не меняется: с чем родился, с тем и живёшь.

Так два «Кинжала теней» из одного моба всё равно разные:

```
IT-34936718   104%   rare    урон 11   ловк 3   Добротный Кинжал теней
IT-4FF76CDE   101%   epic    урон 12   ловк 4   Крепкий Кинжал теней
IT-F9E438EB    96%   rare    урон  9   ловк 3   Добротный Кинжал теней
```

### 🔨 Крафт, ⚗️ алхимия и заточка

На карте стоят NPC-ремесленники трёх типов — **кузнец** (оружие и броня),
**алхимик** (зелья и эликсиры) и **ювелир** (аксессуары и магические
фокусы). У каждого свои рецепты.

**Алхимия** работает на реагентах, которые сыплются со всех мобов
понемногу: уголь саламандры, вечный лёд, громовая соль, слеза тьмы,
корень мандрагоры, пыльца рассвета. Из пустого флакона и травы гонится
дистиллят — основа всех зелий. Дальше варятся эликсиры характеристик
(силы, ловкости, прозрения, стойкости, удачи), настой полного исцеления и
философский раствор.

- **Крафт** — тратятся материалы и золото, на выходе снова *уникальный*
  экземпляр со свежими статами. У сложных рецептов есть шанс брака.
- **Заточка** — существующий предмет улучшается за золото и материалы,
  добытые гриндом. Каждый уровень поднимает статы на долю от базы;
  при неудаче уровень сохраняется, но ресурсы сгорают.

Рецепты, ингредиенты и правила заточки настраиваются в
**Контент → 🔨 Крафт** без правки кода.

### 👣 Живой мир: популяция мобов

Мобы больше не «прибиты» к клетке навсегда:

- в локации держится ровно `population` живых экземпляров каждого моба;
- убили одного — новый появится через `respawn_seconds`, но **сверх лимита
  никто не заспавнится**;
- живые мобы ходят по проходимым клеткам своей локации;
- **слабый моб может забрести в локацию уровнем выше, сильный к слабым —
  нет**: переход разрешён, только если `min_level` цели не ниже
  `min_level` его домашней локации;
- моб, с которым идёт бой, стоит на месте до конца схватки.

Мир тикает раз в 20 секунд фоновой задачей бота
(`bot/runner.py` → `core/spawns.tick`). Текущее состояние видно в
**Контент → 👣 Популяция**.

### 🏪 Лавка и 🎒 инвентарь

Списки предметов оформлены одинаково (общий модуль `engine/itemui.py`):

- в инлайн-кнопках **только эмодзи** — номер `1️⃣…🔟` и иконка предмета,
  по 5 в ряд; никакого текста в кнопках списка;
- что скрыто за номером — написано в тексте сообщения: название, тип,
  редкость и цена;
- нажатие номера открывает **карточку**: бонусы расписаны словами
  (⚔️ Урон +10, 🏃 Ловкость +3) и появляются кнопки действий;
- больше 10 предметов — включается листалка `⬅️ 2/3 ➡️`, а возврат из
  карточки ведёт на ту же страницу.

| Где | Кнопки в карточке |
|---|---|
| 🏪 Лавка → 🛒 Купить | **Купить** (прячется, если не хватает золота) |
| 🏪 Лавка → 💰 Продать | **Продать** — остаёмся в лавке |
| 🎒 Инвентарь | **Надеть** / **Снять**, для зелий — **Использовать**, плюс **Продать** и **Выбросить** |

У лавки две вкладки, активная помечена точками: `• 🛒 Купить •` / `💰 Продать`.

## 🛠 Что умеет админка

- **Сводка** — метрики и топ героев
- **Бот** — токен, запуск/остановка, транспорт, рассылка, живой лог
- **Игроки** — карточка с вкладками: обзор, характеристики, инвентарь,
  VIP и доступ, чат
- **Инвентарь игрока** — правка статов каждого экземпляра, перекат, надеть/снять,
  выдача предметов с уникальными статами или строго по шаблону
- **Мир** — карта всех локаций, редактор клетки, перегенерация по seed
- **Экземпляры** — все именные вещи с их ID, происхождением, статами и
  историей владельцев
- **Аукцион** — лоты, оборот, снятие лотов с витрины
- **Контент** — мобы, популяция, лут, крафт, классы, события, NPC, квесты
- **Действия** — журнал: кто из админов что сделал, из панели или из бота
- **Настройки** — экспорт/импорт JSON, сброс

Состояние хранится в localStorage браузера.

## 🔑 Админка внутри бота и вход в панель

### Те же функции прямо в Telegram

Команда `/admin` (или кнопка **🛠 Админка** в меню) открывает админ-раздел
в самом боте. Разделы показываются по правам игрока:

| Раздел | Что можно | Нужное право |
|---|---|---|
| 📊 Сводка | метрики мира, счётчик админов и порталов | `view_dash` |
| 👥 Игроки | список, карточка, исцеление, предметы, ±золото, ±уровень, телепорт | `view_players` и далее по действию |
| 👑 Доступ | выдать/отозвать ранг, сменить пароль | `grant_admin` |
| 🕳 Порталы | открыть/закрыть портал подземелья | `dungeons` |
| 📣 Рассылка | отправить текст всем игрокам | `broadcast` |
| 📜 Журнал | последние действия админов | любому админу |

Каждое действие проходит проверку права: без него бот отвечает
всплывающим «Нужно право «…»» и ничего не меняет.

### Синхронизация с панелью

И бот, и панель вызывают один слой — `engine/adminops.py`. Поэтому:

- состояние общее (один `Store`), правка из бота сразу видна в панели;
- любое действие пишется в общий журнал `engine/audit.py` с пометкой
  источника (🤖 Бот / 🖥 Панель) — он и есть вкладка **📜 Действия**;
- уведомления игрокам складываются в общую очередь (`outbox`) и уходят,
  как только бот запущен, кто бы ни нажал кнопку.

### Вход в панель без 404

GitHub Pages — статика: серверного маршрута `/admin-login` там нет, поэтому
ссылка из бота раньше отдавала **404**. Прокладка:

```
admin-login/index.html   страница входа — ловит /admin-login?uid=...
admin-login.html         тот же вход рядом с корнем
404.html                 ловит любой неизвестный путь и уводит на нужный,
                         сохраняя ?uid= (учитывает путь /<repo>/ на Pages)
```

Логин — Telegram ID, пароль игрок берёт в боте (`/admin` → **🔑 Логин и пароль**).
После входа `webapp/session.py` поднимает сессию, и панель показывает только
разрешённые разделы; в подвале меню появляется кнопка **Выйти**.

> Вход проверяется по данным в localStorage, значит работает на устройстве,
> где панель уже открывали. Полноценный вход с любого устройства даёт
> серверный запуск (`launch.py`) — там маршрут `/admin-login` настоящий.
