# 🌑 Shadow Lands — Telegram MMORPG

Тёмно-фэнтезийная MMORPG в Telegram с открытым миром на клетках 10×10, полностью inline-интерфейсом и веб-админ-панелью.

## ☁️ Быстрый старт — деплой на Render.com (бесплатно, 24/7)

Этот способ **не требует установки ничего на компьютер**. Бот будет работать в облаке постоянно.

### 1. Форкни репозиторий на GitHub
Нажми кнопку **Fork** вверху страницы репозитория — это создаст твою копию.

### 2. Зарегистрируйся на Render.com
Перейди на [render.com](https://render.com), залогинься через GitHub.

### 3. Создай Web Service
1. Dashboard → **New +** → **Web Service**
2. Выбери свой форк репозитория `Shadow-Lands`
3. Настройки:
   - **Name**: `shadow-lands`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python launch.py`
   - **Plan**: `Free`
4. Нажми **Create Web Service**

### 4. Получи публичный URL
После деплоя Render даст тебе ссылку вида `https://shadow-lands-xxx.onrender.com` — это твоя админка.

### 5. Настрой бота через админку
1. Открой админку по ссылке от Render
2. Перейди в **⚙️ Настройки**
3. Вставь токен от @BotFather
4. Нажми **Сохранить** → **Запустить бота**
5. Готово! Бот работает 24/7 в облаке.

> 💡 **Зачем GitHub?** Render автоматически забирает код из GitHub при каждом `git push`. Ты пушишь изменения — Render перезагружает сервер. Не нужно ничего копировать вручную.

## 💻 Локальный запуск (для разработки)

Если хочешь тестировать перед деплоем:

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python launch.py
```

Админка откроется на http://localhost:8000

## 🗺 Игровой мир

- **Открытый мир 10×10** — каждая локация это сетка клеток
- **Движение в 4 стороны** — Север, Юг, Запад, Восток
- **Мини-карта** — показывает врагов, стены и твоё положение
- **Враги на клетках** — иди по миру и ищи 👾

## 🎮 Возможности

- **4 класса**: Воин, Маг, Разбойник, Жрец
- **5 локаций**: от безопасной деревни до логова дракона
- **Пошаговые бои** с прокачкой
- **Инвентарь** с экипировкой
- **Лавка торговца**
- **Топ игроков**

│   ├── database.py    # SQLite / PostgreSQL
