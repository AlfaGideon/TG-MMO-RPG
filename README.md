# 🌑 Shadow Lands — Telegram MMORPG

Тёмно-фэнтезийная MMORPG в Telegram с полностью inline-интерфейсом и веб-админ-панелью. Бот и админка работают в одном процессе — управляй всем через браузер.

## 🚀 Быстрый старт (3 шага)

### 1. Установи зависимости

```bash
python -m venv venv

# Linux / Mac:
source venv/bin/activate

# Windows:
venv\Scripts\activate.bat

pip install -r requirements.txt
```

### 2. Запусти сервер

```bash
# Linux / Mac:
./run.sh

# Windows:
run.bat
```

Или вручную:
```bash
python launch.py
```

### 3. Открой админку

Перейди в браузере по адресу: **http://localhost:8000**

- Перейди в раздел **⚙️ Настройки**
- Вставь токен от @BotFather
- Нажми **Сохранить**, затем **Запустить бота**
- Открой своего бота в Telegram и нажми `/start`

> 💡 **Важно:** пока работает программа на твоём ноутбуке — бот доступен всем игрокам. Не закрывай терминал.

## 🎮 Возможности игры

- **Inline-интерфейс** — вся игра через кнопки, без команд
- **4 класса**: Воин, Маг, Разбойник, Жрец
- **5 локаций**: от безопасной деревни до логова древнего дракона
- **Пошаговые бои** с 6 видами монстров
- **Инвентарь** с экипировкой
- **Лавка торговца**
- **Прокачка**: уровни, статы, опыт
- **Топ игроков**

## 🛡 Админ-панель

| Страница | Описание |
|----------|----------|
| Dashboard | Статистика, последние бои |
| Игроки | Список всех персонажей с поиском |
| Предметы | Ассортимент магазина |
| Бои | История всех боёв |
| **Настройки** | **Управление ботом: токен, старт/стоп** |

## 🗂 Структура проекта

```
TG-MMO-RPG/
├── launch.py          # ← Единая точка входа (запускай это)
├── bot/               # Telegram бот (aiogram 3)
│   ├── runner.py      # Управление жизненным циклом бота
│   ├── handlers/      # Обработчики кнопок
│   ├── keyboards/     # Inline-клавиатуры
│   └── utils/         # Тексты и утилиты
├── admin/             # Веб-админка (FastAPI)
│   ├── templates/     # HTML-шаблоны
│   └── static/        # CSS
├── core/              # Ядро
│   ├── models.py      # SQLAlchemy модели
│   ├── database.py    # Подключение к SQLite
│   ├── seed.py        # Демо-контент
│   └── enums.py       # Перечисления
├── run.sh / run.bat   # Скрипты запуска
└── requirements.txt
```
