# 🌑 Shadow Lands — Telegram MMORPG

Игровой движок и админ-панель **целиком на Python**.
`index.html` — только загрузчик: поднимает Python в браузере (Pyodide) и отдаёт
ему управление. Игровой логики на JavaScript нет.

---

## 🖥 Запуск админки (превью в Arena / локально)

Открой **`index.html`** через preview или локальный сервер:

```bash
python3 -m http.server 8000     # затем http://localhost:8000/index.html
```

> Через `file://` не заработает — модули подгружаются по fetch.

Дальше в панели: вкладка **🤖 Бот** → вставь токен от [@BotFather](https://t.me/BotFather)
→ **Запустить бота**. Бот начнёт отвечать в Telegram, пока открыта вкладка.

### Если бот не стартует

Telegram с осени 2025 отклоняет запросы с браузерным User-Agent. В разделе
**🤖 Бот → Транспорт** переключи режим с «Напрямую» на любой прокси-релей
(corsproxy / allorigins / codetabs) или укажи свой и нажми «Применить».
Для постоянной работы 24/7 используй серверный запуск (см. ниже).

## 🗂 Структура

```
index.html              загрузчик Pyodide (единственный JS, ~40 строк)
webapp/static/admin.css оформление

engine/                 правила игры — чистый Python, без зависимостей
  data.py               контент: классы, локации, мобы, предметы, NPC
  models.py             Cell / Player / Reply
  world.py              генерация бесшовного мира 5×(10×10)
  rules.py              формулы урона, статы, прокачка
  combat.py             пошаговый бой
  inventory.py          сумка, экипировка, использование, продажа
  texts.py              тексты сообщений бота
  game.py               роутер действий: action → Reply
  storage.py            состояние (игроки, мир, настройки)
  permissions.py        права и ранги админов
  adminops.py           админ-операции — одна реализация для бота и панели
  audit.py              общий журнал действий админов
  adminmenu.py          экраны админки внутри бота
  adminroute.py         роутер admin-кнопок бота (adm:*)
  adminbot.py           вход в админку и выдача доступа

webapp/                 админ-панель
  boot.py               точка входа
  app.py                навигация и рендер (83 строки)
  telegram.py           Bot API + long polling
  transport.py          прямой доступ или прокси-релей
  dom.py                тонкая обёртка над DOM
  html.py               хелперы разметки
  backend.py            localStorage / память
  session.py            кто вошёл: владелец или админ с /admin-login
  pages/                страницы: dashboard, bot, players, world, content, audit, settings
  actions/              обработчики кнопок: audit / bot / content / player / world

admin-login/index.html  прокладка входа для GitHub Pages (нет серверных маршрутов)
admin-login.html        тот же вход рядом с корнем
404.html                ловит неизвестные пути и уводит на нужную страницу

tests/                  проверки без браузера
```

Правила модульности (их стережёт `tests/test_wiring.py`):
`engine/` не импортирует ни `js`, ни `webapp`; `pages/*` только возвращают HTML-строки
и не трогают DOM; ни один файл не длиннее 320 строк; каждый `data-act` из разметки
обязан иметь обработчик в `actions/`.

### Как модули взаимодействуют

```
index.html ──fetch .py──> Pyodide FS ──> webapp/boot.py
                                             │
                    webapp/app.py ───────────┴──── webapp/pages/*.py (HTML-строки)
                          │
          ┌───────────────┼────────────────┐
   webapp/telegram.py  engine/storage.py  webapp/dom.py
          │                   │
   webapp/transport.py   engine/game.py ──> combat / world / rules / texts / data
          │
   api.telegram.org
```

`engine/` ничего не знает ни про браузер, ни про Telegram — его можно
подключить к серверному боту без изменений.

## 🎮 Что умеет игра

- 4 класса, прокачка, статы, экипировка по слотам
- Бесшовный мир: 5 локаций по 100 клеток, переходы по границам
- Движение в 8 направлениях, осмотр клетки, ASCII-карта
- Пошаговый бой: атака, защита, умение, побег, криты и уклонения
- Лут, сундуки, лавка, продажа, зелья, отдых, таблица лидеров

## 🛠 Что умеет админка

- **Сводка** — метрики и топ героев
- **Бот** — токен, запуск/остановка, транспорт, рассылка, живой лог
- **Игроки** — правка статов, выдача предметов, лечение, удаление
- **Мир** — карта всех локаций, редактор клетки, перегенерация по seed
- **Контент** — справочник мобов, предметов, NPC, классов
- **Действия** — журнал: кто из админов что сделал, из панели или из бота
- **Настройки** — экспорт/импорт JSON, сброс

Состояние хранится в localStorage браузера.

## 🔑 Админка внутри бота и вход в панель

### Те же функции прямо в Telegram

Команда `/admin` (или кнопка **🛠 Админка** в меню) открывает админ-раздел
в самом боте. Разделы показываются по правам игрока:

| Раздел | Что можно | Нужное право |
|---|---|---|
| 📊 Сводка | метрики мира, счётчик админов и порталов | `view_dash` |
| 👥 Игроки | список, карточка, исцеление, предметы, ±золото, ±уровень, телепорт | `view_players` и далее по действию |
| 👑 Доступ | выдать/отозвать ранг, сменить пароль | `grant_admin` |
| 🕳 Порталы | открыть/закрыть портал подземелья | `dungeons` |
| 📣 Рассылка | отправить текст всем игрокам | `broadcast` |
| 📜 Журнал | последние действия админов | любому админу |

Каждое действие проходит проверку права: без него бот отвечает
всплывающим «Нужно право «…»» и ничего не меняет.

### Синхронизация с панелью

И бот, и панель вызывают один слой — `engine/adminops.py`. Поэтому:

- состояние общее (один `Store`), правка из бота сразу видна в панели;
- любое действие пишется в общий журнал `engine/audit.py` с пометкой
  источника (🤖 Бот / 🖥 Панель) — он и есть вкладка **📜 Действия**;
- уведомления игрокам складываются в общую очередь (`outbox`) и уходят,
  как только бот запущен, кто бы ни нажал кнопку.

### Вход в панель без 404

GitHub Pages — статика: серверного маршрута `/admin-login` там нет, поэтому
ссылка из бота раньше отдавала **404**. Прокладка:

```
admin-login/index.html   страница входа — ловит /admin-login?uid=...
admin-login.html         тот же вход рядом с корнем
404.html                 ловит любой неизвестный путь и уводит на нужный,
                         сохраняя ?uid= (учитывает путь /<repo>/ на Pages)
```

Логин — Telegram ID, пароль игрок берёт в боте (`/admin` → **🔑 Логин и пароль**).
После входа `webapp/session.py` поднимает сессию, и панель показывает только
разрешённые разделы; в подвале меню появляется кнопка **Выйти**.

> Вход проверяется по данным в localStorage, значит работает на устройстве,
> где панель уже открывали. Полноценный вход с любого устройства даёт
> серверный запуск (`launch.py`) — там маршрут `/admin-login` настоящий.

## ✅ Тесты

```bash
python3 tests/run_all.py
```

| Набор | Что проверяет |
|---|---|
| `test_engine.py` | мир, персонаж, движение, бой, экономика, прокачка, сохранение |
| `test_pages.py` | рендер всех страниц и форм, экранирование XSS |
| `test_transport.py` | сборка URL для direct и прокси-режимов |
| `test_access.py` | права, ранги, карта игрока, ссылка входа |
| `test_admin_sync.py` | админка в боте, права на действия, общий журнал, прокладка входа |
| `test_wiring.py` | манифест, порядок загрузки, связь кнопок, чистота слоёв |

Всё выполняется без браузера обычным `python3`.
