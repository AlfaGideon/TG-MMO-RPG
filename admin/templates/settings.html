🚀 Replit — обновление в 1 клик

  1. Нажми кнопку 🔄 Обновить с GitHub выше.
  2. Если появилось "Обновлено, перезапуск..." — просто подожди 5 секунд, сервер сам перезапустится.
  3. Если не перезапустился — нажми Stop, затем Run в Replit.

Альтернатива: открой вкладку Shell в Replit и напиши git pull origin main, затем Stop → Run.

📖 Первый запуск (локально / Render)

  1. Напиши @BotFather в Telegram, создай нового бота и скопируй токен.
  2. Вставь токен в поле выше и нажми Сохранить.
  3. Нажми Запустить бота. Статус должен стать зелёным.
  4. Открой своего бота в Telegram и нажми /start.
