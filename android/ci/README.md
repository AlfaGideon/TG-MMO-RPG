# CI для сборки APK — одноразовая активация

Файл [`android.yml`](android.yml) — это GitHub Actions workflow, который
собирает, подписывает и публикует APK. Лежит не в `.github/workflows/`,
а здесь, потому что автоматический агент Arena не имеет права создавать
workflow-файлы через API (правило безопасности GitHub). Активируется один
раз вручную, под вашим аккаунтом владельца репозитория:

## Активация (2 минуты, без клонирования)

1. Откройте в браузере:
   **<https://github.com/AlfaGideon/TG-MMO-RPG/new/main/.github/workflows>**
2. В поле имени файла введите: `android.yml`
3. Откройте [`android.yml`](android.yml) в репозитории, нажмите **Raw**,
   скопируйте всё содержимое и вставьте в редактор на GitHub.
4. Нажмите **Commit changes… → Commit changes**.

Готово. Теперь:

- каждый новый **релиз** (тег `vX.Y.Z`) автоматически собирает APK,
  прикреплёт его к релизу файлом `shadow-lands.apk` **и положит копию
  прямо в репозиторий** — `android/dist/shadow-lands.apk` (можно скачивать
  из дерева проекта, не заходя в Releases);
- вручную сборка запускается на вкладке
  **Actions → Android APK → Run workflow** (APK будет в артефактах прогона).

## Первая сборка после активации

Самый быстрый способ сразу получить APK и настроенный канал автообновления —
создать релиз (можно прямо с веб-страницы
[Releases → Draft a new release](https://github.com/AlfaGideon/TG-MMO-RPG/releases/new),
тег `v1.0.0`). Workflow запустится сам и через 10–15 минут APK появится
в активах релиза — оттуда его можно скачать на телефон и установить.
Дальше приложение будет обновляться само.

> Если позже будете менять сам workflow, правки уже скопированного
> `.github/workflows/android.yml` можно коммитить обычным путём —
> ограничение действует только на создание нового workflow-файла.
