# Блок «Мир» — разбор проблем и план доработки

> **Статус: выполнено.** Все три шага реализованы и покрыты тестами
> (`tests/test_worldgen.py` — серверное ядро, секция «Динамические
> локации» в `tests/test_engine.py` — браузерный стек, полный прогон —
> `python3 tests/run_all.py`).

Документ-план. Договорённости с владельцем: улучшаем **оба стека**
(серверный `admin/`+`bot/`+`core/` и браузерный `webapp/`+`engine/`),
работаем по шагам **баги → мастер создания → бот**, `min_level` локации —
предупреждение без блокировки, быстрый travel — только в посещённые
безопасные локации.

---

## 1. Что болело до доработки

### Серверный стек (`admin/` + `bot/` + `core/`)

1. **Новая локация недостижима.** `/editor/location/new` создавал клетки,
   но не связывал локацию с соседями по мировой сетке. Сид связывал только
   стартовые 5 локаций цепочкой запад↔восток. Игрок не мог попасть в новую
   локацию, пока админ вручную не пропишет `target_*` каждой пограничной
   клетки (16+ клеток на пару соседей).
2. **Нет проверки связности.** `_ensure_connectivity` жил только в
   `core/seed.py`; новая локация могла получить изолированный спавн и
   «мёртвые» карманы за стенами.
3. **Пограничные ворота могли упираться в стену.** Ссылка ставилась на
   границу, но проходимость от центра локации до границы никто не
   гарантировал — переход работал «в никуда».
4. **Коллизии координат.** Две локации можно было поставить в одну клетку
   мировой карты — одна исчезала из редактора; перемещение не перестраивало
   переходы.
5. **Смена `grid_size`/`floors_count`** в форме сохранения меняла только
   число в БД: клетки не досоздавались и не обрезались, в шаблоне
   появлялись дыры «—».
6. **Лестницы между этажами — односторонние:** вниз цель ставилась,
   обратной ссылки на верхнюю клетку не было; игрок застревал на этаже.
7. **Удаление локации** оставляло висячие `target_location_id` в чужих
   локациях (переход молча не срабатывал) и сирот в `characters`,
   `mob_spawns`, `quests`, `visited_cells` (на Postgres — IntegrityError).
8. **`min_level` локации не проверялся для игроков** — герой 1 уровня
   свободно заходил в «Логово Пожирателя» (10+).
9. **В боте нет карты мира** — только карта текущей локации.

### Браузерный стек (`webapp/` + `engine/`)

1. **Локации захардкожены в `engine/data.py`** — ровно 5 штук, добавить из
   панели невозможно.
2. **Вкладка «🌐 Сетка мира 10×10» — декоративная:** координаты писались в
   `settings["world_grid"]`, но `engine/world.py` строил переходы
   захардкоженной цепочкой 0→1→2→3→4 и настройки не читал.

## 2. Шаг 1 — баги и ядро (серверный стек)

Новый модуль **`core/worldgen.py`** — единая логика мира для сида, админки
и бота:

- `ensure_connectivity(cells, grid_size)` — BFS от центра, недосягуемое
  становится стеной (перенесено из `seed.py`, сид переиспользует).
- `build_cells(session, loc, stories)` — генерация клеток всех этажей с
  проверкой связности.
- `ensure_stairs(session, loc)` — **дусторонние** лестницы между этажами в
  центре сетки (работает для любого grid_size ≥ 3).
- `neighbor(session, loc, direction)` / `link_pair(session, a, b, dir)` —
  бесшовные переходы по общей границе соседних локаций на мировой карте
  (все 4 стороны, разные `grid_size` — по меньшей границе) + **прорубка
  дорог** от центра до каждых ворот, чтобы переход всегда был досягаем.
- `autolink(session, loc)` — связать со всеми соседями;
  `relink_all(session)` — пересобрать все швы по текущим координатам
  (после перемещений локаций).
- `move_location(session, loc, wx, wy)` — переезд с защитой от коллизий:
  занятая клетка → **обмен местами** с занимающей локацией.
- `resize(session, loc, new_size, new_floors)` — реальная миграция клеток:
  дорастить/обрезать (с проверкой игроков в обрезаемой зоне), перелинковка
  границ, лестницы.
- `validate(session, loc)` — диагностика: коллизия координат, недосягаемые
  клетки, висячие/односторонние переходы, ворота в стену, несвязанные
  соседи; `autofix(session, loc)` — чинит то, что можно.
- `deps(session, loc)` + `safe_delete(session, loc)` — отчёт о зависимостях
  и удаление с зачисткой: игроки → безопасная локация, чужие переходы →
  `NULL`, спавны/визиты — удалить, квесты отвязать.

`core/seed.py` переходит на `worldgen` (долой дублирование).

### Админка (`admin/main.py` + шаблоны)

- **Создание:** чекбоксы «🔗 Связать с соседями» (вкл. по умолчанию) и
  «📍 Автоподбор свободных координат» (вкл.); заняты координаты и автоподбор
  выключен → понятная ошибка, а не тихая коллизия.
- **Сохранение:** смена `grid_size`/`floors_count` → `resize`; смена
  мировых координат → `move_location` (обмен при коллизии) + перелинковка.
- **Удаление:** страница подтверждения со списком зависимостей
  (`editor_location_delete.html`), затем `safe_delete`.
- **Новые операции:** «🔗 Связать с соседями», «✅ Диагностика» +
  «🔧 Починить» (`editor_location_validate.html`), на карте мира —
  «🔗 Пересобрать все переходы».

## 3. Шаг 2 — бот (`bot/`)

- **Предупреждение по `min_level`:** при входе в локацию уровнем выше —
  alert «⚠️ Опасно для вашего уровня», вход разрешён (по договорённости).
- **🌍 Карта мира** (кнопка на экране карты): рендер мировой сетки 10×10 —
  посещённые локации с иконкой типа, текущая подсвечена, непосещённые под
  туманом; счётчик «Исследовано N из M».
- **🏠 Быстрый travel:** под картой — список посещённых **безопасных**
  локаций; телепорт к центру локации. В небезопасные/непосещённые — нельзя.

## 4. Шаг 3 — браузерный стек (`engine/` + `webapp/`)

- `engine/data.py::LOCATIONS` остаётся источником дефолтов, но становится
  изменяемым списком: `Store` подменяет его содержимое из
  `settings["locations"]` — все потребители (`texts`, `mapview`,
  `adminmenu`, страницы) видят динамику без правок.
- `engine/world.py::generate(seed, locations, grid)` — переходы строятся по
  **соседству на мировой сетке** (`world_grid`), а не цепочкой; заселение по
  типу локации (NPC — в первую безопасную, сундуки — в опасные/подземелья/
  боссовую). Старый вызов без аргументов ведёт себя как раньше.
- `Store.add_location(...)` / `Store.remove_location(li)` — добавление
  достраивает клетки новой локации и связывает её с соседями (чужие
  рукоправные клетки не трогаются); удаление реиндексирует клетки/игроков/
  переходы/порталы, сохраняя ручные правки остальных локаций.
- Вкладка «🗺 Локации»: карточка управления списком (➕ добавить, 🗑
  удалить с подтверждением). Сетка мира становится боевой: её координаты
  реально определяют швы.
- Формы клеток/сетки вынесены в `webapp/pages/world_forms.py`, чтобы
  уложиться в лимит 320 строк (стерёгёт `tests/test_wiring.py`); модуль
  добавлен в `modules.json` и FALLBACK `index.html`.
- Браузерный бот: предупреждение по `min_level` при переходе.
